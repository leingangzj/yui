M5Stack Cardputer ADV firmware — flash from your browser.

Your browser doesn't support the Web Serial API. Use Chrome, Edge, or Brave on a desktop OS, or follow the esptool instructions below.

1. Plug in the device

Connect the Cardputer ADV to this computer with a USB-C cable. A cable that only carries power won't work — it has to enumerate a serial port.

2. Click install

The browser will prompt you to pick a serial port. The Cardputer usually shows up as USB JTAG/serial debug unit or CDC ACM.

Flashing takes about 90 seconds at 921600 baud. The device will reboot into the splash on its own when finished.

What gets flashed

  • Version: v0.3 (code-complete, hardware bring-up pending)
  • Image: yui-v0.3-cardputer_adv.bin — single merged image at offset 0x0 bundling bootloader + partitions + firmware (~1.9 MB)
  • Target chip: ESP32-S3 (qio, 80 MHz, 8 MB flash)

If the browser button doesn't work

Web Serial only runs in Chromium-based browsers (Chrome, Edge, Brave, Opera) on a desktop OS. Two fallbacks:

esptool

Grab the .bin from the latest release and run: 

python3 -m esptool --chip esp32s3 -p /dev/ttyACM0 -b 921600 \
  write_flash --flash_mode qio --flash_freq 80m --flash_size 8MB \
  0x0 yui-v0.3-cardputer_adv.bin

Replace /dev/ttyACM0 with COM3 (or similar) on Windows, or /dev/cu.usbmodem* on macOS.

M5Burner

Open M5Burner, pick Custom Firmware, drag the .bin from the release page in. Hit Burn.

After it boots

  1. Splash → launcher.
  2. WiFi → Wifi: pick your AP, type the passphrase. NTP runs on its own.
  3. System → Settings: pick a timezone.
  4. (TH-D75 owners) Radio → Kenwood, Tab to scan for the bb-link bridge.
  5. (Pineapple owners) Set host/user/pass in NVS via serial, then WiFi → Pineapple.

Full reference: USING.md.

Heads-up on RF

Several apps transmit RF or inject 802.11 management frames. Only point them at spectrum, networks, and devices you own or have written authorization to test. Deauth, beacon flood, BLE-spam, and captive-portal phishing against unconsenting parties is a federal crime in the US (CFAA, Wiretap Act, FCC Part 15) and the equivalent elsewhere.
